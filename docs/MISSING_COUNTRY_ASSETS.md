# Missing country map assets

This checklist covers all 250 countries and territories in
`assets/json/us/countries.json`.

Place the completed files in `assets/image/countries/`:

- `<code>.png` is the isolated country or territory silhouette.
- `<code>-full.png` is the locator map with the country or territory highlighted.
- File names must use the lowercase country code shown in the table.
